# Security

Do not commit credentials, cookies, request headers, personal transaction
records, raw social-media snapshots, local databases, media, or purchased
market data. Use environment variables or the operating-system credential
store for local integrations.

If a secret is found in a published mirror, stop using it, revoke it at the
provider, and report the affected revision privately to the repository owner.
Public exports are generated by an allowlist and checked for credential-like
patterns before publication.
